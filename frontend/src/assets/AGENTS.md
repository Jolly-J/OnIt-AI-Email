# 打包资源指南

继承[源码指南](../AGENTS.md)。本目录资源需要被源码 import 才会进入对应依赖图；直接 URL 引用的文件放在 `frontend/public/`。

- 当前 `hero.png`、`react.svg`、`vite.svg` 在源码中未发现引用，是脚手架资源候选，不代表获得删除授权。
- 新增资源先确定用于哪个组件，再按项目实际方式导入；核对大小、透明背景、比例和打包结果。
- 企业 logo 的设计源文件在根目录 `品牌资源/`，运行副本在 `public/`；不要在这里另存不明来源的品牌版本。
- 修改或删除前用 `rg` 检查所有引用，并检查动态路径；资源任务以界面实际呈现验证，不仅检查文件存在。
