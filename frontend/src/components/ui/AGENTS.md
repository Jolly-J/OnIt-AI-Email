# 公共交互组件指南

继承[组件指南](../AGENTS.md)。这里承载多个业务入口复用的反馈样式与确认交互。

- `AlertDialog.tsx`：通过 props 控制打开、标题、说明、按钮与确认/取消回调，支持不同提示类型。修改接口前搜索全部调用者，保留关闭过渡和 Escape 等已有行为。
- `Toast.tsx`：封装 Sonner 的 Toaster 外观并导出 toast；全局 Toaster 在 App 挂载，不在每个弹窗再创建一个。
- 色彩、边框、按钮状态与根主题保持一致。公共组件中不加入邮箱、员工或钉钉业务查询。
- 验证确认只执行一次、取消不执行业务动作、忙碌状态清晰、长说明可读、层级与滚动正确；焦点及键盘支持以实际测试为准，不把现有组件描述为已满足完整无障碍标准。
- 公共样式修改要查看 AICopilot、AccountDialog 等实际调用场景，不能只看孤立示例。
